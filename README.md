# 贪吃蛇大作战 🐍

一个网页版「贪吃蛇大作战（Slither.io 风格）」小游戏，单文件 HTML，打开即玩，无需任何依赖。

## 玩法

- 鼠标移动 / 手指拖动转向，吃满地彩色光球，越吃越长、越吃越胖
- 限时 1 分钟，时间到按「长度 = 金币」结算（长度多少就给多少金币）
- 撞到别的蛇身或红色边界就出局
- 按住鼠标 / 双指加速冲刺（会消耗长度并掉落食物）

## 特色

- **30 款皮肤**：流光渐变、卡通人物（猫/狐/熊猫/兔…）、齿轮与转盘
- **可爱表情**：蛇头随机带 12 种表情，也能用金币解锁自己选
- **皮肤抽奖**：花 5/10/20 金币抽普通/稀有/传说皮肤，也可能开出金币、空手、或 🛡️无敌 10 秒
- **表情抽奖 + 游戏内发送**：抽到的表情可在游戏里通过圆盘/齿轮载体发出，含嘲讽款
- **无敌 10 秒**：激活后撞谁谁死、你不会死（边界仍致死）
- **本地存档**：金币、皮肤、表情、最高分都存在浏览器 localStorage

## 运行

直接用浏览器打开 `snake-game.html` 即可。也可访问 GitHub Pages 在线版本。

## 操作

| 操作 | 键盘 | 触屏 |
|------|------|------|
| 转向 | 鼠标移动 | 手指拖动 |
| 暂停 | 空格 | — |
| 无敌技能 | Q | 左下角按钮 |
| 表情面板 | E | 右下角按钮 |
